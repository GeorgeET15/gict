What it actually does

No exaggerated claims — just what the code does today.

  • SHA-256 verification

    Every copied file is hashed and verified against the source before it counts as backed up.

  • Timestamped snapshots

    Each run creates its own dated snapshot directory, so backups never silently overwrite each other.

  • Backup reports

    Every snapshot gets a report.json and a status marker — COMPLETE or INCOMPLETE — so you always know what happened.

  • Local-directory mode

    Back up any local folder the same verified way, with no iPhone or device tools required.

  • Interactive terminal UI

    Run gict with no arguments for a guided, keyboard-driven interface — or use flags to script it.

  • Guided dependency setup

    A built-in System Setup screen checks each iPhone-access requirement individually and shows example install commands.

How it works

  1. 1

    Connect, or choose a folder

    Connect and trust your iPhone over USB, or point GICT at a local directory you want backed up.

  2. 2

    Pick a destination and confirm

    Choose where the backup goes and review it on a confirmation screen. Nothing is mounted, copied, or overwritten until you confirm.

  3. 3

    Copy, verify, review

    Files are copied into a timestamped snapshot, every file is SHA-256 verified, and a report tells you exactly what succeeded or failed.

Quick start

Install

Using pipx:

pipx install git+https://github.com/GeorgeET15/gict-portable.git

Check it installed:

gict --version

Local-directory backup

Works anywhere GICT runs — no iPhone or device tools needed.

gict --source ./photos --backup-root ~/GICT_Backups

Or run gict with no arguments and choose "Back up a local directory" in the interactive interface.

iPhone backup (Linux only)

Unlock and connect your iPhone over USB, then trust the computer when prompted.

gict --list-devices
gict --device-id DEVICE_ID --backup-root ~/GICT_Backups

iPhone device access is Linux-only; it is not supported on macOS or Windows. Local-directory mode doesn't need any of this.

Linux requirements for iPhone device mode

  • Python 3.10+
  • ifuse — exactly version 1.2.1
  • idevice_id and ideviceinfo
  • mountpoint
  • fusermount3 or fusermount

Run gict, open System Setup from the home screen, and it will check each of these individually and show an example install command for your distribution — GICT never installs anything itself.

Requirements & safety

Runs on your machine

GICT is a local terminal application. This website is documentation only — it does not access your iPhone, your files, or your backups, and it does not perform any backup itself.

Platform & dependencies

iPhone device mode requires Linux and the exact dependency versions listed above. Local-directory mode has no device dependencies.

Verification isn't a backup strategy

SHA-256 verification confirms files copied correctly — it doesn't replace keeping an independent copy of anything you can't afford to lose.
